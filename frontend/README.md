# Front-end — Chirp (React + Vite)

## Como rodar

```bash
cd frontend
copy .env.example .env
npm install
npm run dev
```

App em: http://127.0.0.1:5173/

A API padrão é `http://127.0.0.1:8000`. Para usar a API no Render, ajuste `VITE_API_URL` no `.env`.

## Scripts

| Comando | Descrição |
|---------|-----------|
| `npm run dev` | Servidor de desenvolvimento |
| `npm run build` | Build de produção |
| `npm run preview` | Preview do build |
| `npm run lint` | Oxlint |
